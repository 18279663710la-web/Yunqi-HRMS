# utils 目录说明

## 职责

异步路由封装、错误与响应、日期、密码和发票等工具。

## 主要内容

- 主要文件：`asyncHandler.ts`、`datetime.ts`、`errors.ts`、`invoice.ts`、`leaveDuration.ts`、`password.ts`、`response.ts`。

## 维护约束

优先放置跨模块基础设施、类型和通用工具；保留全局错误处理和现有调用约定。
