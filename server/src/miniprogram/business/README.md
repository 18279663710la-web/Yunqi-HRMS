# 业务员接口

`u9Routes.ts` 先验证员工会话、实时职务及 U9 绑定，再查询本人关联单据或下载 PDF；应收单和收款单列表的记账期间、客户均可留空，两者都为空时默认上月。客户池接口返回名称、拼音首字母和全拼（pinyin-pro 生成，按业务员和期间缓存 5 分钟），keyword 留空返回全量池供小程序本地联想，非空时服务端也按名称/拼音过滤；应收单详情按单号返回本人明细字段。汇总 PDF 只接受期间从，期间到由服务端固定为当月，按 U9 原报表透视成矩阵；收款单 PDF 使用整单结算明细（行号、结算方式、流水号、金额、银行账号），与回款通知列表一致，访问范围仍按出货明细业务员校验。汇总按 U9 原报表的客户当前负责人归属。回款通知接口按登录员工读取本人留单、未读数和详情，并在打开详情时标记已读；绑定由超级管理员通过管理端维护。

本模块功能与接口已随业务模块收尾冻结，除不改变行为与口径的性能优化外不再修改。
