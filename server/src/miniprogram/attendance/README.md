# attendance 目录说明

## 职责

员工普通考勤、设置查询、记录、加班打卡及拜访登记接口。

## 主要内容

- 主要文件：`attendanceRoutes.ts`、`visitRoutes.ts`。
- 员工设置接口只返回时段和半径，不返回打卡点经纬度。
- 拜访接口提供现场照片上传、拜访提交、本人当月拜访记录和当前位置逆地址解析；照片按员工隔离，仅本人和管理端可读取，逆解析未配置 Key 时回退“当前位置”。

## 维护约束

员工端入口沿用员工和董事长鉴权、入职限制及响应约定；双端共用的规则按业务归属复用。考勤管理功能优化已完成，后续优化不得修改本目录的接口和行为，除非用户提出硬性且明确的修改要求。详见项目根目录 `AGENTS.md`。
