# workbench 目录说明

## 职责

公司信息、工作台快捷入口、审批类型及发布表单、待办统计、演示数据重置及员工本人工资条查询、鉴权下载和已读接口。

## 主要内容

- 主要文件：`companyRoutes.ts`、`demoRoutes.ts`、`statsService.ts`、`todoRoutes.ts`、`payslipRoutes.ts`。

## 维护约束

人事管理功能优化已完成，后续优化不得修改工资条接口的现有行为，除非用户提出硬性且明确的修改要求。本目录的公司信息、待办和演示重置不因此整目录冻结。详见项目根目录 `AGENTS.md`。
