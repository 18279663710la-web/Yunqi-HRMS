# onboarding 目录说明

## 职责

员工本人待填写入职申请的查询、附件上传、删除未进入提交历史的附件和提交接口。

## 主要内容

- 主要文件：`onboardingFormRoutes.ts`。

## 维护约束

人事管理功能优化已完成，后续优化不得修改员工入职填写接口的现有行为，除非用户提出硬性且明确的修改要求。详见项目根目录 `AGENTS.md`。
