# approvals 目录说明

## 职责

员工审批列表、详情、申请、处理及已发布流程 AI 失败重试接口。报销预审接口已移除。新申请按发布版本校验表单和分支并固定路径，旧单继续原流程。审批人预览同时返回当前报销路径的查重和验伪开关。

## 主要内容

- 主要文件：`approvalsRoutes.ts`。

## 维护约束

员工端入口沿用员工鉴权、入职限制及响应约定；双端共用的规则按业务归属复用。
