# attendance 目录说明

## 职责

管理端考勤查询、设置、考勤组维护、人工补录和拜访记录查询；部分计算复用共享考勤领域。

## 主要内容

- 主要文件：`adminAttendanceService.ts`、`routes.ts`。
- 人工补录与员工打卡锁同一条当日记录。员工不能覆盖已登记的缺卡。明细状态筛选接受出差；顶部汇总仍把出差天数并入正常，员工汇总和月度导出不随该筛选改变。
- 考勤组接口提供列表、新建、编辑和删除；新建/编辑同时保存组设置与员工成员，删除后成员改用第一个考勤组。
- 拜访记录接口按月份、员工和关键字查询，并提供受管理员鉴权保护的现场照片读取。

## 维护约束

管理端入口沿用管理员鉴权与权限校验；跨端规则按实际归属复用共享业务，不复制实现。
