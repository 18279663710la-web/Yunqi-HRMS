# models-formulas 目录说明

## 职责

入职申请表模板、公司日历、附件鉴权下载和薪资构成模型的管理接口；部分绩效规则接口仍位于 `admin/hr/`。离职申请表设置已删除。

## 主要内容

- 主要文件：`companyCalendarRoutes.ts`、`onboardingFormRoutes.ts`、`salaryModelsRoutes.ts`。
- 公司日历接口读取对所有管理员开放（考勤组编辑需要选择规则），新建、修改和删除仅超级管理员；被考勤组使用的规则不能删除。

## 维护约束

模型与公式功能优化已完成，后续优化不得修改本目录的公司日历、入职申请表模板和薪资构成模型接口，除非用户提出硬性且明确的修改要求。薪资构成模型、工资批次、工资发放、工资发放记录的原有保护继续有效。详见项目根目录 `AGENTS.md`。

沿用管理端鉴权、审计及现有事务和行锁；部分人事与入职表路由仍包含 SQL，继续分层时不得改变业务行为。
