# employees 目录说明

## 职责

员工主档、小程序账号、职务和组织目录及 U9 业务员绑定的管理端入口；员工主档的管理服务位于此处。

## 主要内容

- 主要文件：`adminEmployeeService.ts`、`routes.ts`、`u9Routes.ts`。

## 维护约束

员工与账号功能优化已完成，后续优化不得修改员工主档、小程序账号、启停、密码、列表和 U9 绑定的现有行为，除非用户提出硬性且明确的修改要求。本目录 `routes.ts` 中的组织目录和职务目录接口属于组织架构；后续若用户要求修改组织架构，只能改那些接口，不能改员工账号行为。详见项目根目录 `AGENTS.md`。
