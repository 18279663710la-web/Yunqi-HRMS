# U9 业务领域

`sqlServerGateway.ts` 使用参数化查询读取 U9 的业务员、出货关联应收和收款，并调用 U9 原有汇总过程；过程所需筛选条件仅由校验后的业务员 ID 生成。应收单列表可按记账期间、客户或两者组合查询；两者都为空时默认上个月。有期间时以 `BusinessDate` 范围做索引预过滤并精确匹配 `PostPeriod`；客户选中时按 `AccrueCust_Customer` 索引过滤；客户联想按业务员和期间缓存后在内存中模糊匹配。收款单列表使用相同条件，按 `h.Cust_Customer`/客户名称和 `h.BusinessDate`/`PostPeriod` 过滤，收款单客户联想同样按业务员与期间缓存。应收单列表与详情按业务员过滤出货明细，按单号聚合表头与本人明细行，返回客户、期间、组织、发票信息及物料、数量、单价、金额、到期日等字段。`receiptNotificationService.ts` 按 U9“收款单审核发送”规则定时轮询已审核及之后的收款单，按表头业务员绑定写入回款通知快照；轮询起点、组织、回看天数和间隔由环境配置，重复轮询由通知唯一键去重。`money.ts` 使用十进制字符串按币种精度处理金额，`pdf.ts` 生成应收单 PDF、收款单 PDF 和应收款汇总矩阵 PDF；汇总表按“承上 + 各月 + 合计”透视，期间到固定当月。

SQL Server 连接使用服务进程的 Windows 身份，部署时须限制数据库权限。此目录不写入 U9 永久数据；汇总过程使用临时表。对应员工绑定和权限入口分别位于管理端与小程序端。
