# attendance 目录说明

## 职责

考勤规则、打卡数据、设置和加班打卡；供员工端及管理端复用。

## 主要内容

- 主要文件：`attendancePolicy.ts`、`attendanceService.ts`、`attendanceSettings.ts`、`overtimeAttendanceService.ts`。

## 维护约束

维护本领域业务规则或数据访问；复用现有事务与领域能力，不把本端专用接口混入共享实现。
