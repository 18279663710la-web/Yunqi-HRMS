# offboarding 目录说明

## 职责

离职申请表字段模板定义；与人事交接清单 `hr_offboarding` 分离，本目录当前仅提供模板字段校验复用与默认模板。

## 主要内容

- 主要文件：`offboardingForm.ts`。

## 维护约束

维护本领域业务规则；字段 schema 复用入职申请表校验，不把本端专用接口混入共享实现。登记填写生命周期尚未接入。
