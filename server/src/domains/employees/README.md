# employees 目录说明

## 职责

当前员工、公司、部门、职务目录及通讯录相关查询。首次迁移以旧职位分类作为统一职务并保留旧工资明细的显示值；被员工使用的职务不可删除。

## 主要内容

- 主要文件：`userService.ts`、`jobTitleService.ts`。

## 维护约束

维护本领域业务规则或数据访问；复用现有事务与领域能力，不把本端专用接口混入共享实现。
