# employees 目录说明

## 职责

当前员工、公司、组织、职务目录及通讯录相关查询。组织平级，旧部门名称保留供历史异动展示，迁移后员工默认未分配；首次职务迁移保留旧工资明细显示值。被员工使用的组织或职务不可删除。

## 主要内容

- 主要文件：`userService.ts`、`jobTitleService.ts`、`organizationService.ts`。

## 维护约束

维护本领域业务规则或数据访问；复用现有事务与领域能力，不把本端专用接口混入共享实现。
