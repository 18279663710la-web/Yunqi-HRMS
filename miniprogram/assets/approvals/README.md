# approvals — 审批类型图标

## 职责

小程序审批发起页「审批类型」入口的白色图标资源，铺在类型卡片自身的彩色圆角块上。

## 主要内容

- `leave.png`：请假（日历）。
- `expense.png`：报销（人民币符号）。
- `overtime.png`：加班（时钟）。
- `travel.png`：出差（纸飞机）。
- `purchase.png`：采购（购物袋）。
- `custom.png`：自定义审批（单据），未匹配内置类型的审批编号使用该图标。

图标为透明底白色图形，192×192，页面按 60rpx 显示；卡片底色与透明度仍由接口返回的颜色和页面样式决定。

## 维护约束

图标仅在 WXML 中按审批类型 `key` 引用，不写入业务字段；新增内置类型时补一张同规格 PNG，并在 `pages/approval-create/approval-create.wxml` 增加对应分支。不引入外部图标库。
