# login 目录说明

## 职责

员工账号登录页面；登录后依据账号和入职状态选择入口。

## 主要内容

- 主要文件：`login.json`、`login.ts`、`login.wxml`、`login.wxss`。
- 长按底部“云启科技 · 企业办公”可手动设置真机后端地址，留空恢复自动探测；用于校园网、手机热点等地址切换。

## 维护约束

保持 app.json 中的页面注册路径和现有跳转、分享路径；修改时同步检查 TS、WXML、WXSS 和 JSON。
