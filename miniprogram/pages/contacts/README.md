# contacts 目录说明

## 职责

员工通讯录列表页面，按职务目录筛选并搜索在职员工。

## 主要内容

- 主要文件：`contacts.json`、`contacts.ts`、`contacts.wxml`、`contacts.wxss`。

## 维护约束

保持 app.json 中的页面注册路径和现有跳转、分享路径；修改时同步检查 TS、WXML、WXSS 和 JSON。
