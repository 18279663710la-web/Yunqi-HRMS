# approval 目录说明

## 职责

审批中心页面，展示待处理、我发起及已办结列表。

## 主要内容

- 主要文件：`approval.json`、`approval.ts`、`approval.wxml`、`approval.wxss`。

## 维护约束

保持 app.json 中的页面注册路径和现有跳转、分享路径；修改时同步检查 TS、WXML、WXSS 和 JSON。
