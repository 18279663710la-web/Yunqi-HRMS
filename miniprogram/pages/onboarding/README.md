# onboarding 目录说明

## 职责

员工入职申请填写页面，负责字段、相册/拍照/聊天记录附件、照片、声明及提交交互。

## 主要内容

- 主要文件：`onboarding.json`、`onboarding.ts`、`onboarding.wxml`、`onboarding.wxss`。

## 维护约束

保持 app.json 中的页面注册路径和现有跳转、分享路径；修改时同步检查 TS、WXML、WXSS 和 JSON。
