# onboarding 目录说明

## 职责

员工入职申请填写页面，负责字段、相册/拍照/聊天记录附件、删除附件、照片、声明及提交交互。数字字段按模板上下限校验。

## 主要内容

- 主要文件：`onboarding.json`、`onboarding.ts`、`onboarding.wxml`、`onboarding.wxss`。

## 维护约束

人事管理功能优化已完成，后续优化不得修改入职填写页的现有行为，除非用户提出硬性且明确的修改要求。保持 app.json 中的页面注册路径和现有跳转、分享路径。详见项目根目录 `AGENTS.md`。
