# index 目录说明

## 职责

员工工作台页面，展示快捷入口、待办和公告，并检查入职状态。

入职检查通过后检查未读工资条并弹出提醒。

## 主要内容

- 主要文件：`index.json`、`index.ts`、`index.wxml`、`index.wxss`。

## 维护约束

保持 app.json 中的页面注册路径和现有跳转、分享路径；修改时同步检查 TS、WXML、WXSS 和 JSON。
