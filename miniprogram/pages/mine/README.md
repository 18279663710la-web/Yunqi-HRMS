# mine 目录说明

## 职责

员工个人中心页面，提供本人信息、业务入口及退出登录。

提供“我的工资条”入口。底部品牌名和“关于”弹窗标题使用小程序名称「云启办公」；办公地址、工作时间和考勤规则读取公司配置，未配置时显示「未配置」。

## 主要内容

- 主要文件：`mine.json`、`mine.ts`、`mine.wxml`、`mine.wxss`。

## 维护约束

保持 app.json 中的页面注册路径和现有跳转、分享路径；修改时同步检查 TS、WXML、WXSS 和 JSON。
