# onboarding-required 目录说明

## 职责

待入职员工的引导页面，提供进入填写和切换账号的入口。

## 主要内容

- 主要文件：`onboarding-required.json`、`onboarding-required.ts`、`onboarding-required.wxml`、`onboarding-required.wxss`。

## 维护约束

保持 app.json 中的页面注册路径和现有跳转、分享路径；修改时同步检查 TS、WXML、WXSS 和 JSON。
