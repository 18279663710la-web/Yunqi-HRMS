# invoice-tool 目录说明

## 职责

独立发票工具台，提供图像读码、查重及验真交互。

## 主要内容

- 主要文件：`invoice-tool.json`、`invoice-tool.ts`、`invoice-tool.wxml`、`invoice-tool.wxss`。

## 维护约束

保持 app.json 中的页面注册路径和现有跳转、分享路径；修改时同步检查 TS、WXML、WXSS 和 JSON。
