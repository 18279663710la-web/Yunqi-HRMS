# visit 页面说明

## 职责

员工客户拜访登记与本人本月拜访记录查看；拜访仅记录，不改变考勤状态。

## 主要内容

- 主要文件：`visit.ts`、`visit.wxml`、`visit.wxss`、`visit.json`。
- 登记客户名称、拜访目的、自动获取当前位置并逆解析为地图地点名称与地址（不允许选择或修改）和 1–3 张现场照片；提交后照片随拜访记录入库。
- 记录列表按当前月份读取本人数据，可预览现场照片并下拉刷新。
- 逆解析依赖服务端 `TENCENT_MAP_KEY` 和腾讯位置服务额度；未配置、额度用尽或调用失败时显示“当前位置”，不显示经纬度。

## 维护约束

沿用 `services/attendance/api.ts` 请求封装和页面定位、图片选择方式；定位权限与 `app.json` 的 `requiredPrivateInfos` 保持一致。考勤管理功能优化已完成，后续优化不得修改本页的现有行为，除非用户提出硬性且明确的修改要求。详见项目根目录 `AGENTS.md`。
