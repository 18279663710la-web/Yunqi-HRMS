# onboarding-signature 目录说明

## 职责

入职申请的横屏手写签名页面，通过页面事件回传结果。

## 主要内容

- 主要文件：`onboarding-signature.json`、`onboarding-signature.ts`、`onboarding-signature.wxml`、`onboarding-signature.wxss`。

## 维护约束

保持 app.json 中的页面注册路径和现有跳转、分享路径；修改时同步检查 TS、WXML、WXSS 和 JSON。
