# attendance 目录说明

## 职责

员工考勤页面，负责普通打卡与已审批加班打卡交互。

## 主要内容

- 主要文件：`attendance.json`、`attendance.ts`、`attendance.wxml`、`attendance.wxss`。
- 当日已登记缺卡时不提供打卡。加班上班卡过了申请结束时间后按钮不可用；已打上班卡的下班卡仍可跨日。

## 维护约束

保持 app.json 中的页面注册路径和现有跳转、分享路径；修改时同步检查 TS、WXML、WXSS 和 JSON。考勤管理功能优化已完成，后续优化不得修改本页的现有行为，除非用户提出硬性且明确的修改要求。详见项目根目录 `AGENTS.md`。
