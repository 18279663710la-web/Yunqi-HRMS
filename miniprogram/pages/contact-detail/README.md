# contact-detail 目录说明

## 职责

员工联系人详情页面及分享入口。

## 主要内容

- 主要文件：`contact-detail.json`、`contact-detail.ts`、`contact-detail.wxml`、`contact-detail.wxss`。

## 维护约束

保持 app.json 中的页面注册路径和现有跳转、分享路径；修改时同步检查 TS、WXML、WXSS 和 JSON。
