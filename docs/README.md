# docs 目录说明

## 职责

项目专题说明，包括目录职责、架构边界、薪资发放口径及 U9 原报表导出对接建议；不记录凭据或业务数据。

## 主要内容

- 主要文件：`薪资发放开发说明.md`、`项目目录职责说明.md`、`U9原报表导出接口文档.md`（待确认的对接建议，尚未实现）。
- `superpowers/specs/`：经确认的设计说明（如 U9 MySQL 镜像与分阶段缓存）；实现前以该目录文档为准，实现后需与代码保持一致。
- `superpowers/plans/`：对应设计的分步实现计划（任务勾选、文件落点与验证）。

## 维护约束

文档应以实际代码和配置为依据；职责或架构变化时同步更新，不记录凭据、个人路径或业务数据。
