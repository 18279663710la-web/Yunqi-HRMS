# 项目目录职责说明

本文按当前代码记录目录用途及职责边界。项目只有一个 Express 服务和一套共享 MySQL；`admin/` 与 `miniprogram/` 是服务端内的代码边界，不是独立部署的服务。

各长期维护目录另有 `README.md`，记录本目录职责、主要内容及维护约束；依赖、构建产物、运行时文件、缓存和历史备份快照不逐级创建说明。

## 项目根目录

| 目录或文件 | 当前作用与职责范围 |
| --- | --- |
| `server/` | 服务端工程，负责两端 API、业务逻辑、数据库及后台任务；拥有独立依赖、构建和说明。 |
| `web/` | React 管理后台工程，负责管理员界面和管理 API 调用；拥有独立依赖、构建和说明。 |
| `miniprogram/` | 原生微信小程序工程，负责员工界面和员工 API 调用；拥有独立依赖、类型检查和说明。 |
| `docs/` | 项目专题文档，包括本文和薪资发放开发说明；不存放凭据或业务数据。 |
| `代码备份/` | Git 启用前的历史代码快照与回滚说明；后续代码版本管理及回退使用 Git。 |
| `发票样本/` | 本地发票识别和查验相关样本；不属于应用源码。 |
| `.zcode/`、`.zcode/plans/` | 工作过程中的工具目录及计划文档；不是应用运行代码。 |
| `.playwright-cli/` | 浏览器自动化产生的快照和日志；不是产品源码。 |
| `AGENTS.md`、`README.md`、`开发日志.md` | 分别记录项目约束、使用说明和变更历史；模块规则以各自 `AGENTS.md` 为准。 |
| `package.json`、`project.config.json`、`project.private.config.json` | 分别提供跨模块脚本、微信开发者工具项目配置和本地项目配置。 |

## 服务端：`server/`

| 目录或文件 | 当前作用与职责范围 |
| --- | --- |
| `src/` | 服务端 TypeScript 源码，包含应用入口、双端接口、业务领域和基础设施。 |
| `src/index.ts` | 启动入口；按配置执行数据库初始化、播种和管理账号初始化，启动 AI 后台任务及 HTTP 监听。 |
| `src/app.ts` | 创建 Express 应用，按现有顺序装配双端路由、上传静态资源、404 和全局异常处理。 |
| `src/config.ts` | 读取环境配置；不在文档中记录配置值或凭据。 |
| `src/admin/` | Web 管理端接口与仅管理端使用的服务；`adminRoutes.ts` 聚合主要管理路由，`adminContext.ts` 读取管理员上下文。 |
| `src/admin/admin-accounts/` | 管理员登录、鉴权、会话、密码和管理员账号管理。 |
| `src/admin/approvals/` | 管理端审批人和报销规则配置接口；审批执行逻辑位于共享审批领域。 |
| `src/admin/attendance/` | 管理端考勤查询、设置和人工补录；部分计算复用共享考勤领域。 |
| `src/admin/dashboard/` | 管理端仪表盘、组织查询和操作日志接口；组织相关管理接口当前位于此目录。 |
| `src/admin/employees/` | 员工主档、小程序账号、董事长账号及职务目录的管理端入口。 |
| `src/admin/hr/` | 人事管理接口及入职任务、员工档案、合同、薪资批次、工资发放补充项与发放快照、离职和人事异动相关服务；合同文件已拆出服务和数据访问。 |
| `src/admin/models-formulas/` | 入职表模板、薪资构成模型与薪资流程的管理接口；部分绩效规则接口仍位于 `admin/hr/`。 |
| `src/miniprogram/` | 员工小程序端 API 及本端专用认证、业务入口；不负责 Web 管理员鉴权。 |
| `src/miniprogram/auth/` | 员工及董事长登录、令牌、当前用户和员工端鉴权限制。 |
| `src/miniprogram/approvals/` | 员工审批列表、详情、申请、处理及报销预审接口。 |
| `src/miniprogram/attendance/` | 员工普通考勤、设置查询、记录及加班打卡接口。 |
| `src/miniprogram/contacts/` | 员工可访问的组织、部门和通讯录接口。 |
| `src/miniprogram/invoices/` | 发票图片上传、查重、查验及旧 OCR 接口。 |
| `src/miniprogram/notices/` | 员工公告列表、详情及未读相关接口。 |
| `src/miniprogram/onboarding/` | 员工本人待填写入职申请的查询和提交接口。 |
| `src/miniprogram/workbench/` | 公司信息、工作台快捷入口、待办统计、演示数据重置及员工本人工资条接口。 |
| `src/domains/` | 跨端业务规则和可复用服务；不是所有业务都已迁入，具体职责见下列子目录。 |
| `src/domains/accounts/` | 董事长账号及员工会话版本、令牌撤销相关逻辑。 |
| `src/domains/approvals/` | 审批流转、审批人配置、报销规则、AI 建议及流式处理。 |
| `src/domains/attendance/` | 考勤规则、打卡数据、设置、加班打卡及按工资月份查询考勤数据；供员工端及管理端复用。 |
| `src/domains/audit/` | 管理员操作日志记录与查询。 |
| `src/domains/employees/` | 当前员工、公司、部门、职务目录及通讯录相关查询。 |
| `src/domains/invoices/` | 发票识别、查重、查验、上传记录及腾讯云查验适配。 |
| `src/domains/notices/` | 公告查询及已读、未读相关逻辑。 |
| `src/domains/onboarding/` | 入职表字段、声明、员工填写规则及本人提交的数据访问。 |
| `src/domains/payroll/` | 薪资模型、工资计算、一键添加、考勤数据绑定、出勤绩效规则模式与加班规则、薪资流程及相关数据访问。 |
| `src/shared/` | 数据库和非业务基础设施；当前类型与工具中也保留部分业务相关定义。 |
| `src/shared/db/` | MySQL 连接池、事务、增量迁移、种子、演示数据和建库入口。 |
| `src/shared/middleware/` | 请求参数校验、404 和全局异常响应；双端鉴权位于各自客户端目录。 |
| `src/shared/types/` | 管理员、员工业务模型及 Express 请求扩展类型。 |
| `src/shared/utils/` | 异步路由封装、错误与响应、日期、密码和发票等工具。 |
| `scripts/` | 员工端、管理端冒烟脚本及历史演示审批清理脚本；运行可能写数据。 |
| `sql/` | 数据库建表结构；增量迁移在 `src/shared/db/pool.ts`。 |
| `tests/`、`tests/fixtures/` | 服务端、跨端单元及集成测试与测试夹具；部分集成测试创建并删除随机临时数据库。 |
| `third_party/`、`third_party/frappe-hr/` | 第三方参考资料及其许可；后者保存人事功能参考来源和对照说明，不是当前服务端运行代码。 |
| `uploads/` | 服务运行时上传文件目录；不作为源码或文档存放位置。 |
| `node_modules/`、`dist/` | 分别为依赖安装结果和 TypeScript 构建产物，不手工维护业务源码。 |

当前分层仍在进行：`admin/hr/hrRoutes.ts`、`admin/hr/hrLifecycleRoutes.ts` 和 `admin/models-formulas/onboardingFormRoutes.ts` 仍包含 SQL、事务或业务逻辑。不要把这些目录误认为已全部完成路由、服务、数据访问分层；后续拆分应保留现有鉴权顺序、事务和行锁。

## Web 管理后台：`web/`

| 目录或文件 | 当前作用与职责范围 |
| --- | --- |
| `src/` | Web 管理后台 TypeScript、React 源码和样式。 |
| `src/main.tsx`、`src/App.tsx` | React 入口、应用级路由及登录保护。 |
| `src/api/` | 共享 HTTP 请求、令牌、下载和错误处理；业务 API 位于各模块。 |
| `src/auth/` | 管理员登录状态和认证上下文。 |
| `src/components/` | 页面标题和子模块标题等跨模块组件。 |
| `src/layout/` | 主侧栏、子栏目、路由展示、工作区页签及相关状态。 |
| `src/modules/` | 按业务分组页面、专用组件、工具和 API。 |
| `src/modules/auth/` | 管理员登录页面及登录、本人信息、修改密码 API。 |
| `src/modules/dashboard/` | 仪表盘页面及统计、日志 API。 |
| `src/modules/employees/` | 员工主档与小程序账号管理页面和 API。 |
| `src/modules/attendance/` | 考勤查询、人工更正和考勤设置页面、组件与 API。 |
| `src/modules/approvals/` | 五类审批配置、审批人及报销规则组件与 API。 |
| `src/modules/organization/` | 职务管理、员工分布展示及部门查询 API。 |
| `src/modules/admin-accounts/` | 管理员账号和董事长小程序账号的管理页面及 API。 |
| `src/modules/hr/` | 人事页面布局、共享人事 API 和子模块组合；六个页面不对应六个实体目录。 |
| `src/modules/hr/onboarding/` | 管理端入职申请、流程、提交内容展示及入职表相关类型。 |
| `src/modules/hr/employee-records/` | 劳动合同文件、人事事件、调岗晋升和定薪历史组件。 |
| `src/modules/hr/payroll/` | 工资批次及 PDF/XLSX 输出、考勤取值预览、工资发放补充项与实发、发放记录及只读快照界面。 |
| `src/modules/hr/offboarding/` | 离职清单、任务和离职确认界面。 |
| `src/modules/models-formulas/` | 模型与公式入口与子页面组合。 |
| `src/modules/models-formulas/attendance/` | 出勤绩效规则页面、区间/单位模式的字段与工具。 |
| `src/modules/models-formulas/overtime/` | 加班绩效规则页面、区间/单位配置及字段。 |
| `src/modules/models-formulas/salary/` | 薪资构成模型页面、独立考勤接口配置弹窗、字段处理和共享薪资模型工具。 |
| `src/modules/models-formulas/onboarding-template/` | 入职表模板设置及 Excel 导出。 |
| `src/modules/models-formulas/payroll-workflow/` | 薪资发放流程画布、节点图标及流程工具；不执行实际发放。 |
| `src/utils/` | 跨模块界面辅助函数；模块专用工具放在业务目录。 |
| `src/pages/` | 旧页面目录，目前仅有目录说明而无页面源码；现有页面实际位于 `src/modules/`。 |
| `src/types.ts`、`src/styles.css` | 全局共享类型与样式。 |
| `tests/` | Web 组件、模型、工具及工作区页签测试；当前 `package.json` 未定义单独测试脚本。 |
| `node_modules/`、`dist/` | 分别为依赖和构建结果，不手工维护业务源码。 |

## 微信小程序：`miniprogram/`

| 目录或文件 | 当前作用与职责范围 |
| --- | --- |
| `app.ts`、`app.json`、`app.wxss` | 应用状态、页面及 tabBar 注册和全局样式；页面路径被跳转、分享和 tabBar 使用。 |
| `pages/` | 小程序页面入口，每页通常包含 TS、WXML、WXSS、JSON；保留现有注册路径。 |
| `pages/login/`、`pages/index/`、`pages/mine/` | 分别为登录、工作台和个人中心；工作台展示未读工资条提醒，个人中心提供历史入口。 |
| `pages/onboarding-required/`、`pages/onboarding/`、`pages/onboarding-signature/` | 分别为入职引导、申请填写和手写签名。 |
| `pages/payslips/` | 员工本人工资条列表及 PDF 查看、保存入口。 |
| `pages/attendance/`、`pages/record/` | 分别为考勤及加班打卡、考勤记录。 |
| `pages/approval/`、`pages/approval-create/`、`pages/approval-detail/` | 分别为审批列表、发起和详情处理。 |
| `pages/contacts/`、`pages/contact-detail/` | 按职务筛选的通讯录列表与联系人详情。 |
| `pages/notice/`、`pages/notice-detail/` | 公告列表与详情。 |
| `pages/invoice-tool/` | 发票工具台。 |
| `components/`、`components/invoice-uploader/` | 小程序可复用组件；目前包含报销发票图片、识别、查重和查验交互组件。 |
| `custom-tab-bar/` | 自定义底部导航及审批角标。 |
| `services/` | 小程序 API 与业务入口；请求由 `utils/request.ts` 统一封装。 |
| `services/auth/` | 登录、退出和当前用户 API。 |
| `services/workbench/` | 工作台、公司信息、待办、演示重置和工资条 API。 |
| `services/approvals/` | 审批查询、提交、处理及报销 AI 流式预审 API。 |
| `services/attendance/` | 考勤、记录和加班打卡 API。 |
| `services/contacts/` | 职务、部门及通讯录 API。 |
| `services/notices/` | 公告及未读数量 API。 |
| `services/invoices/` | 发票图片上传、二维码解析、查重和查验封装。 |
| `services/onboarding/` | 入职引导目的地和入职页面识别；入职页目前也直接通过请求封装调用接口。 |
| `types/` | 小程序业务模型及界面类型。 |
| `utils/` | 请求和登录态、流式处理、发票与二维码、请假时长等工具。 |
| `lib/` | 本地二维码解码库及其类型声明。 |
| `node_modules/` | 本模块安装的开发依赖，不作为业务源码。 |
