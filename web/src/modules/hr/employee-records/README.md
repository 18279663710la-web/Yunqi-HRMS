# employee-records 目录说明

## 职责

劳动合同文件、人事事件、调岗晋升和定薪历史组件；调岗可调整平级组织及职务，不再输入职级，历史异动保留旧部门名称和职级。定薪提交不携带职务。

## 主要内容

- 主要文件：`HrContractFiles.tsx`、`HrEvents.tsx`、`HrTransitions.tsx`、`salaryHistory.ts`。

## 维护约束

按现有业务和子模块维护页面、专用组件及 API；保留路由、全局页签状态和既有权限边界。
