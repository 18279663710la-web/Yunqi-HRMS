# payroll 目录说明

## 职责

工资批次、考勤取值预览、发放登记及发放记录界面。

工资批次采用无标题、无外围卡片的全宽布局；顶部操作栏和历史批次弹窗用于选择及管理批次，表格横向滚动条位于页面底部并与表格同步。

## 主要内容

- 主要文件：`HrPayrollBatches.tsx`、`HrPayrollDisbursement.tsx`、`payrollScroll.ts`。

## 维护约束

按现有业务和子模块维护页面、专用组件及 API；保留路由、全局页签状态和既有权限边界。
