# payroll 目录说明

## 职责

工资批次、考勤取值预览、工资发放页面及发放记录快照界面。

工资批次采用无标题、无外围卡片的全宽布局；顶部操作栏和历史批次弹窗用于选择及管理批次。明细表和一键添加预览遵循模型保存的字段顺序，历史快照独有字段追加；姓名位于首位时固定在左侧，操作列固定在右侧。工资表采用紧凑灰色表头和细网格，使用表格原生横向滚动条及分页。

同月支持多个批次，列表与发放选择显示批次编号，导出文件名包含编号；单人添加禁用当月已复核及当前批次员工，一键添加跳过已复核员工，复核时服务端再检查冲突。

顶部输出入口可将当前批次的全部已保存明细及合计导出为 PDF 或 XLSX，使用居中的“工资表”标题、月份说明、编号表头和黑色网格，沿用字段顺序和历史快照字段；编辑尚未保存时禁用输出。合计行前三列合并显示“本批次合计”，中间字段合并，末尾应发列独立加宽。PDF 读取相同 XLSX 工作表的格式、列宽及行高，所有列缩放到同一页宽，仅按员工行纵向分页；使用浏览器字体绘图，文本不可选择。XLSX 保留数字类型并为长文本设置行高。

草稿的固定薪资字段（包含考勤、绩效结果）和手工扩展字段在单元格中编辑，输入时调用薪资模型计算工具预览行和批次应发，使用明细版本保存后以服务端结果为准；身份字段、考勤来源扩展字段和已复核明细只读。固定字段覆盖仅改变当前明细，保留首次原值，不联动其他字段。模型收入减模型扣款得到应发；工资批次列表、合计及导出只显示应发，历史独立扣除与实发数据保留。

工资发放页面选择月份和当月已复核批次，按模型顺序展示只读原明细。顶部可新增批次共用的数字补充项，各员工独立填写，表格、发放记录和 PDF/XLSX 输出均将补充项放在应发之前；回车或失焦保存、Esc 取消，冲突刷新后重试。服务端按分计算实发；保存和刷新保留横向位置，整页刷新从会话存储恢复经验证的批次和位置。合计位于表格末行之后，PDF/XLSX 输出包含全部员工、补充项及应发和实发合计，发放记录及输出中的应发、实发表头上边界对齐。发放后补充项只读，记录页按批次汇总并在独立页签展示不可变工资表快照；发放前逐人生成不含批次合计行的 PDF 并暂存，服务端验证版本后原子登记发放及发送；已发放批次可逐人重新生成并发送工资条。

## 维护约束

薪资构成模型、工资批次、工资发放、工资发放记录目前暂时收尾；优化其他模块不得改变这四个模块的现有业务逻辑，除非用户提出硬性且明确的修改要求。涉及共享代码、数据或接口时保持行为兼容并验证受影响链路；详见项目根目录 `AGENTS.md` 和薪资发放开发说明。

按现有业务和子模块维护页面、专用组件及 API；保留路由、全局页签状态和既有权限边界。
