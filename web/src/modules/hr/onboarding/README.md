# onboarding 目录说明

## 职责

管理端入职申请、提交内容和附件下载展示及入职表相关类型；入职管理顶部功能区提供登记申请，主列表不使用外围卡片，历史申请存在时只读展示。

## 主要内容

- 主要文件：`api.ts`、`OnboardingForms.tsx`、`OnboardingSubmission.tsx`。

## 维护约束

人事管理功能优化已完成，后续优化不得修改本目录的页面、接口和行为，除非用户提出硬性且明确的修改要求。入职申请表设置属于已冻结的模型与公式。若明确要求修改模板设置，不得改变本目录的登记、打回、封存和历史只读行为。详见项目根目录 `AGENTS.md`。
