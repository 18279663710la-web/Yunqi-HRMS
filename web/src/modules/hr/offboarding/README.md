# offboarding 目录说明

## 职责

离职管理：登记离职申请/已离职、可选附件存档；页面为上方功能区无标题布局，操作栏为离职、刷新。已申请行内可撤销，撤销不改变账号启停或密码；已离职行内可选择复职日期，未到期显示待复职。

## 主要内容

- 主要文件：`HrOffboarding.tsx`。

## 维护约束

人事管理功能优化已完成，后续优化不得修改本目录的页面、接口和行为，除非用户提出硬性且明确的修改要求。不在小程序端发起离职申请。离职申请表设置属于模型与公式，修改模板设置时不得改变本目录的登记、撤销和复职行为。详见项目根目录 `AGENTS.md`。
