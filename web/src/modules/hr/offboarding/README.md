# offboarding 目录说明

## 职责

离职管理：登记离职申请/已离职、可选附件存档；页面为上方功能区无标题布局，操作栏为离职、刷新。已申请行内可撤销，撤销不改变账号启停或密码；已离职行内可选择复职日期，未到期显示待复职。

## 主要内容

- 主要文件：`HrOffboarding.tsx`。

## 维护约束

按现有业务和子模块维护页面、专用组件及 API；保留路由、全局页签状态和既有权限边界。不在小程序端发起离职申请。
