# approvals 目录说明

## 职责

五类审批通过覆盖式子侧栏进入独立页面和全局页签，提供审批人及报销规则配置组件与 API。

## 主要内容

- 主要文件：`api.ts`、`ApprovalManagement.tsx`、`ExpenseApproverSettings.tsx`、`ExpenseRulesSettings.tsx`。

## 维护约束

按现有业务和子模块维护页面、专用组件及 API；保留路由、全局页签状态和既有权限边界。
