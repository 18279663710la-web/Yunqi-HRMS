# approvals 目录说明

## 职责

审批管理包含「审批流程」「自定义审批」和「审批汇总」。审批流程在标题行右侧选择请假、报销、加班、出差、采购或已保存的自定义审批。自定义审批页编辑名称、表单和流程。关闭页签会丢弃未发布草稿，发布成功后页面清空，该审批转入审批流程的类型列表继续编辑。删除按钮只在审批流程中，用于删除已发布的自定义审批；内置五类不能删除。小程序发起页只显示已发布的自定义审批。页面按保存的测试用例测试并发布到小程序新申请。页面不再提供 AI 规则入口。表单设计把原业务字段显示为可编辑字段卡片，可拖动排序。报销的发票附件和补充材料，以及加班的加班日期、开始时间和结束时间，以同样的卡片展示，名称、类型和必填不可改，也不可删除。报销自定义字段可以选择附件类型。报销可添加系统查验节点，并分别开关发票查重和发票验伪；其他类型可添加发起人、审批人、条件分支和结束节点。未发布的内置类型与历史申请仍沿用原审批逻辑。自定义审批不提供指定审批人，审批人写在节点上，未发布时不能提交。
审批汇总在标题行右侧选择审批类型；筛选支持申请日期范围、组织、职务和员工；分组可多选月份、组织、职务和员工；统计字段可多选该审批类型的数字或金额字段，按分组显示合计。表格始终显示申请总数、待审批、已通过、已驳回、已撤销和通过率，并提供合计行。修改筛选条件不会自动查询：浮层底部的「保存」按审批类型记住筛选（日期、组织、职务、员工、分组和统计字段，写入 localStorage），原「重置筛选与汇总」改为按钮放在保存左侧；顶部筛选按钮右侧的「查询」才重新取数。切换审批类型后清空旧结果，需点查询。顶部另有导出 CSV。
报销表单单选字段的选项逐项编辑和增删；保存前校验空白、重复和数量限制。
流程节点配置使用弹窗，条件分支按目标节点分组设置字段、比较方式和条件值。
报销设计稿的 AI 审批节点可配置模型服务、名称、接口地址、API Key 和规则；密钥仅待保存时在页面内存中保留，服务端不回传。测试只检查 URL 连通性；实际发布后节点异步生成建议并交后续人工审批，同一节点自动失败三次后跳过。规则只写在该节点上。
独立设计稿审批人候选为启用了小程序账号的员工（含职务为董事长的员工）；审批人列表在弹窗内展开并独立滚动。未发布的内置类型可在顶部指定原审批人，发布后该入口不再显示。自定义审批没有这个入口。

## 维护约束

按现有业务和子模块维护页面、专用组件及 API；保留路由、全局页签状态和既有权限边界。表单字段及条件字段须与服务端校验同步。
