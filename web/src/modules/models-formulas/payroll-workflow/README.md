# payroll-workflow 目录说明

## 职责

薪资发放流程画布、节点图标及流程工具；不执行实际发放。

## 主要内容

- 主要文件：`PayrollWorkflow.tsx`、`PayrollWorkflowCanvas.tsx`、`PayrollWorkflowIcons.tsx`、`workflowUtils.ts`。

## 维护约束

按现有业务和子模块维护页面、专用组件及 API；保留路由、全局页签状态和既有权限边界。
