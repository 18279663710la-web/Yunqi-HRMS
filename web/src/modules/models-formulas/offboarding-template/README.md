# offboarding-template 目录说明

## 职责

离职申请表模板设置及 Excel 导出，字段和表格子字段可配置附件类型；本目录仅维护模板配置，不含人事登记或小程序填写。

## 主要内容

- 主要文件：`api.ts`、`offboardingExcel.ts`、`OffboardingTemplateSettings.tsx`。

## 维护约束

按现有业务和子模块维护页面、专用组件及 API；保留路由、全局页签状态和既有权限边界。
