# company-calendar 目录说明

## 职责

维护公司日历规则，供考勤组选择。每条规则可配置不固定、每周固定或按周轮换的休息模式，以及例外休息/上班日期；页面与薪资构成模型一致，无标题和外围卡片，操作按钮位于顶部功能区。

## 主要内容

- 主要文件：`CompanyCalendar.tsx`、`api.ts`。
- 规则支持：每周固定星期、2–8 周轮换及起始周、例外休息日期、例外上班日期。
- 例外日期按起止日期范围录入，允许起止同日；可添加多段范围，编辑时连续日期自动合并回范围。
- 被考勤组使用的规则不可删除；同一日期不能同时设置为休息和上班。

## 维护约束

按现有业务和子模块维护页面、专用组件及 API；保留路由、全局页签状态和超级管理员权限边界。
