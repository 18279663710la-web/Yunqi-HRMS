# salary 目录说明

## 职责

薪资构成模型页面、字段处理和独立考勤接口配置弹窗；出勤天数和加班时长可直接输出或分别绑定相应绩效规则。

删除确认框内的操作不会清除所选字段；删除成功后才清除选择。

## 主要内容

- 主要文件：`salaryModel.ts`、`salaryInterfaceConfig.ts`、`salaryCalculation.ts`、`SalaryModels.tsx`；金额预览依据模型字段用途计算并供工资批次调用。

## 维护约束

薪资构成模型、工资批次、工资发放、工资发放记录目前暂时收尾；优化其他模块不得改变这四个模块的现有业务逻辑，除非用户提出硬性且明确的修改要求。涉及共享代码、数据或接口时保持行为兼容并验证受影响链路；详见项目根目录 `AGENTS.md` 和薪资发放开发说明。

按现有业务和子模块维护页面、专用组件及 API；保留路由、全局页签状态和既有权限边界。
