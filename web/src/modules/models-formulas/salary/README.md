# salary 目录说明

## 职责

薪资构成模型页面、字段处理和独立考勤接口配置弹窗；出勤天数和加班时长可直接输出或分别绑定相应绩效规则。

## 主要内容

- 主要文件：`salaryModel.ts`、`salaryInterfaceConfig.ts`、`SalaryModels.tsx`。

## 维护约束

按现有业务和子模块维护页面、专用组件及 API；保留路由、全局页签状态和既有权限边界。
