# overtime 目录说明

## 职责

加班绩效规则页面与字段，支持按区间或按单位设置小时金额。

## 主要内容

- 主要文件：`OvertimeRulesFields.tsx`、`overtimeConfig.ts`、`PayrollOvertimeRules.tsx`。

## 维护约束

按现有业务和子模块维护页面、专用组件及 API；保留路由、全局页签状态和既有权限边界。
