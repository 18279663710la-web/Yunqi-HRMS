# organization 目录说明

## 职责

无标题、无外围卡片展示员工及所属组织；顶部按职务和组织筛选，分别在弹窗维护职务和组织。组织可创建、改名和删除，在用组织不能删除；员工与账号中分配组织。

## 主要内容

- 主要文件：`api.ts`、`Departments.tsx`、`organization.css`。

## 维护约束

按现有业务和子模块维护页面、专用组件及 API；保留路由、全局页签状态和既有权限边界。
