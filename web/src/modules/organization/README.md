# organization 目录说明

## 职责

无标题、无外围卡片展示员工；顶部操作栏提供职务筛选和“编辑”弹窗入口，可在弹窗创建、删除职务；同时提供人事异动所用部门查询 API。

## 主要内容

- 主要文件：`api.ts`、`Departments.tsx`、`organization.css`。

## 维护约束

按现有业务和子模块维护页面、专用组件及 API；保留路由、全局页签状态和既有权限边界。
