# attendance 目录说明

## 职责

考勤管理拆为“考勤组”和“考勤明细”两个子模块页面、组件与 API；职务筛选使用组织架构目录。考勤组不分类型，每组使用同一套打卡时段、公司日历和地图打卡点，并可选择员工；未分配员工使用第一个考勤组。打卡点使用腾讯地图，展示已保存的打卡中心及半径，支持点击地图选点；加载失败时可重试或手动输入坐标。

## 主要内容

- 主要文件：`api.ts`、`AttendanceGroupsPage.tsx`（`/attendance/groups`）、`AttendanceRecordsPage.tsx`（`/attendance/records`）、`attendanceMap.ts`。
- 两页均无标题和外围卡片，按钮位于顶部功能区；考勤组列表以单选行选择组后使用顶部编辑/删除，考勤明细保留筛选、统计与页签表格。
- 公司日历规则在“模型与公式 → 公司日历”维护；考勤组编辑时必须选择一条规则。删除组后成员改用第一个考勤组，同一员工只保留一个考勤组。

## 维护约束

按现有业务和子模块维护页面、专用组件及 API；保留路由、全局页签状态和既有权限边界。
