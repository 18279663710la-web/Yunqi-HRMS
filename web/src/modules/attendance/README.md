# attendance 目录说明

## 职责

考勤查询、人工更正和考勤组页面、组件与 API；职务筛选使用组织架构目录。考勤组不分类型，每组使用同一套打卡时段、公司日历和地图打卡点，并可选择员工；未分配员工使用第一个考勤组。打卡设置使用腾讯地图，展示已保存的打卡中心及半径，支持点击地图选点；加载失败时可重试或手动输入坐标。

## 主要内容

- 主要文件：`api.ts`、`Attendance.tsx`、`AttendanceGroupsCard.tsx`、`attendanceMap.ts`。
- 公司日历规则与设置统一在“模型与公式 → 公司日历”维护；考勤组编辑时必须选择一条规则。删除组后成员改用第一个考勤组，同一员工只保留一个考勤组。

## 维护约束

按现有业务和子模块维护页面、专用组件及 API；保留路由、全局页签状态和既有权限边界。
