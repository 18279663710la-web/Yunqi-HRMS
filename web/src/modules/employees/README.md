# employees 目录说明

## 职责

员工主档与小程序账号管理页面和 API；可在新增或编辑员工时选择平级组织或未分配，并从职务目录选择职务；超级管理员可绑定 U9 业务员。

## 主要内容

- 主要文件：`api.ts`、`u9Api.ts`、`Employees.tsx`。

## 维护约束

按现有业务和子模块维护页面、专用组件及 API；保留路由、全局页签状态和既有权限边界。
