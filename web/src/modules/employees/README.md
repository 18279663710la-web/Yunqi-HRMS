# employees 目录说明

## 职责

员工主档与小程序账号管理页面和 API；顶部功能区提供刷新和新增员工账号，其下是独立筛选区及无外围卡片的列表。新增或编辑员工时可选择平级组织和职务；超级管理员可绑定 U9 业务员。

## 主要内容

- 主要文件：`api.ts`、`u9Api.ts`、`Employees.tsx`。

## 维护约束

员工与账号功能优化已完成，后续优化不得修改本目录的页面、接口和行为，除非用户提出硬性且明确的修改要求。范围包括列表、筛选、分页、新增、编辑、启停、密码和 U9 绑定弹窗。组织架构仍是独立模块。模型与公式已冻结。修改组织架构时不得改变本页现有行为。详见项目根目录 `AGENTS.md`。
