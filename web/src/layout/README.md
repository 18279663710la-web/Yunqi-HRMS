# layout 目录说明

## 职责

主侧栏、子栏目、路由展示、工作区页签及相关状态；人事管理、模型与公式和审批管理使用覆盖式子栏目。

## 主要内容

- 主要文件：`AdminLayout.tsx`、`AdminPageRoutes.tsx`、`subModules.tsx`、`WorkspaceContext.ts`、`workspaceTabs.ts`。

## 维护约束

沿用 React、现有路由、Ant Design 和共享请求封装；按业务模块组织新增页面和组件。
