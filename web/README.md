# web 目录说明

## 职责

React 管理后台工程，提供管理员界面、页面路由、业务 API 与构建配置。

## 主要内容

- 子目录：[src/](src/README.md)、[tests/](tests/README.md)。
- 主要文件：`package.json`、`tsconfig.json`、`vite.config.ts`。

## 维护约束

沿用 React、现有路由、Ant Design 和共享请求封装；按业务模块组织新增页面和组件。

## 常用命令

`npm run dev`、`npm run typecheck`、`npm run build`。
